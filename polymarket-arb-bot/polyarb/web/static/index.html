    一鍵轉實盤步驟（Zeabur）
    1. 先以紙盤運行一段時間，確認「執行成功率」、「略過原因」及持倉都合理。
    2. 「地區檢查」必須通過。按 Polymarket 官方地區規則，日本、南韓、愛爾蘭、荷蘭只限制網頁版投注，API 下單不受限，所以 Zeabur 東京伺服器可以直接實盤；美國、英國、新加坡、台灣、德國、法國等地則連 API 下單也受限。若顯示 ✕，用專案內的 deploy/zeabur.py --region hkg1 把同一套設定部署到准許的地區（例如 Zeabur 香港）。萬一 Polymarket 以 HTTP 403 拒絕訂單，機器人會即時熔斷停手。切勿用 VPN 或代理繞過；你本人所在地亦須合法使用 Polymarket。
    3. 準備專用錢包，只存放打算投入的 pUSD。未設 POLYMARKET_WALLET 時使用此私鑰的 Deposit Wallet（經 relayer 送交易，免 gas）；轉實盤後本卡會顯示實際的入金地址。私鑰只放在 Zeabur 環境變數，切勿貼到其他地方。
    4. 在 Zeabur 服務 →「環境變數」加入：
      POLYARB_MODE=live
      POLYARB_LIVE_CONFIRM=yes
      POLYMARKET_PRIVATE_KEY=0x…
      POLYMARKET_WALLET=0x…（Polymarket 代理錢包才需要）
    5. 建議首次實盤調低上限：
      POLYARB__RISK__BANKROLL_USD=200
      POLYARB__RISK__MAX_TRADE_USD=25
      POLYARB__RISK__MAX_HOLD_EXPOSURE_USD=150
    6. 按 Zeabur「重新啟動」。頂部徽章由「紙盤」變成「實盤」即代表成功；任何條件未通過，系統會自動維持紙盤並在頂部顯示原因。
    7. 隨時可按「暫停交易」，或把 POLYARB_MODE 改回 paper 再重啟。紙盤與實盤的帳本分開保存。

    系統日誌CONSOLE

    POLYARB 結構性套利仍有執行、結算及平台風險；紙盤結果不代表實盤表現。
